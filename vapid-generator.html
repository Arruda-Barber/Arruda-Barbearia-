Gerador de chaves VAPID

Gere um novo par de chaves para habilitar notificações push no site.

Privacidade: as chaves são geradas exclusivamente neste iPhone, dentro do navegador. Esta página não envia, salva ou compartilha nenhum valor com servidores.

Copie a chave privada diretamente para Supabase → Edge Functions → Secrets, no campo VAPID_PRIVATE_KEY. Não coloque essa chave no GitHub nem no código do site. Guarde a pública para enviar ao suporte da configuração.
